# Roadmap

Workers Release Proof is in its initial public-adoption phase. Usage numbers
and compatibility claims will be reported only when they can be reproduced
from public evidence.

## 0.2

- [x] publish JSON Schemas for configuration and evidence;
- [x] add an end-to-end public Cloudflare Workers reference deployment;
- [x] document compatibility across Wrangler binding and environment shapes;
- [x] add tamper-focused tests for health and rollback evidence;
- [x] publish a verification guide for release attestations.

## 1.0

- stabilize the evidence schema and migration policy;
- document at least two independently reproduced adoption cases;
- publish response targets for bug and security reports;
- keep a public compatibility and deprecation table.

Roadmap work is tracked in GitHub issues. Priorities may change based on
maintainer capacity, security findings, and user feedback.
