# Support

Use GitHub Discussions for usage questions and the issue templates for
reproducible bugs or feature proposals.

Do not publish credentials, private endpoints, production response bodies,
customer data, or proprietary configuration. Security vulnerabilities should
follow [SECURITY.md](SECURITY.md).

Include the package version, Node.js version, command, sanitized configuration,
and minimal reproduction.

The maintainer targets an initial response to complete bug reports within five
business days and reviews feature proposals during the active milestone.
Security reports follow the private response targets in
[SECURITY.md](SECURITY.md). These are maintainer targets rather than guaranteed
service-level agreements.
